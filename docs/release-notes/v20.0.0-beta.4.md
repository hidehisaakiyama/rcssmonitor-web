The fourth beta of rcssmonitor-web, a browser-based monitor for the RoboCup Soccer Simulator 2D server (rcssserver). It fixes the 3D view on computers without a graphics card. Everything else is as in beta.3: opening game logs on the web by their URL (beta.3) and the 3D view (beta.2).

**This is a pre-release** for trying it out and for feedback. The major version follows rcssserver: this beta is for the asio-based rcssserver that will be released as version 20, the first with WebSocket connections. The stable 20.0.0 will come when the repository moves to the rcsoccersim organization; the GitHub Pages address below changes then.

## Downloads

- **rcssmonitor-web-v20.0.0-beta.4.html**: the whole app in one file. Save it and open it from disk (`file://`) to replay logs and to connect to a server anywhere on your LAN.
- **rcssmonitor-web-v20.0.0-beta.4-dist.zip**: the multi-file build, to serve from your own web server.
- The same version runs on GitHub Pages (https://hidehisaakiyama.github.io/rcssmonitor-web/), for logs and servers on `localhost`. A page served over HTTPS cannot open `ws://` connections to other machines.

## Fixed

- **The ground of the 3D view on integrated graphics.** On a Windows machine without a graphics card (the integrated Radeon of a Ryzen 7 7700), the 3D view flickered, and at some camera angles the field's lines and grass stripes disappeared. The plain green around the field, laid a little below it, showed through it on graphics with less depth precision. The ground is now layered by the order it is drawn in, which does not depend on the graphics hardware. Nothing changes on computers that showed it correctly.

## Not included

Binary logs (v1–v3), the UDP / TCP transports and the S-expression protocols, and Qt-specific features (window style, quit, auto quit).

## Known limitations of this beta

- The 3D view keeps 60 fps at 1920×1080 in Firefox on a desktop GPU with everything on. Without a GPU (software rendering), it is much slower; turning off the shadows helps the most.
- Tested with headless Chrome and Firefox on Linux, against the replay server and against the asio-based rcssserver on the same machine; the 3D fix also on the Windows machine where the problem was found. Not tested yet: browser shortcuts that the app takes over (Ctrl+1–0, Ctrl+I, Ctrl+L, F11 and others) in desktop browsers, connections from another machine on the LAN, connections from the GitHub Pages version to `localhost`, and Safari.
