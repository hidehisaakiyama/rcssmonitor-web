The third beta of rcssmonitor-web, a browser-based monitor for the RoboCup Soccer Simulator 2D server (rcssserver). It opens game logs on the web by their URL, also from GitHub repositories. The 3D view came in beta.2.

**This is a pre-release** for trying it out and for feedback. The major version follows rcssserver: this beta is for the asio-based rcssserver that will be released as version 20, the first with WebSocket connections. The stable 20.0.0 will come when the repository moves to the rcsoccersim organization; the GitHub Pages address below changes then.

## Downloads

- **rcssmonitor-web-v20.0.0-beta.3.html**: the whole app in one file. Save it and open it from disk (`file://`) to replay logs and to connect to a server anywhere on your LAN.
- **rcssmonitor-web-v20.0.0-beta.3-dist.zip**: the multi-file build, to serve from your own web server.
- The same version runs on GitHub Pages (https://hidehisaakiyama.github.io/rcssmonitor-web/), for logs and servers on `localhost`. A page served over HTTPS cannot open `ws://` connections to other machines.

## New: open a game log from a URL

- **File > Open Game Log from URL** downloads a log and opens it, without saving it first. The status bar shows the download's progress; opening another log or connecting to a server stops the download.
- **The URL parameter `log`** opens a log at start-up, as a log file on rcssmonitor's command line does (it comes before `connect`). A link then shows a game in one click, and it can carry the other URL parameters of the view:

  ```
  https://hidehisaakiyama.github.io/rcssmonitor-web/?log=https://github.com/rcsoccersim/RoboCup2026/blob/main/logs/Finals/202607050404-HELIOS2026_0-vs-YuShan2026_1.rcg.gz
  ```

  Escape `&`, `#` and `+` in the log's URL (`encodeURIComponent`).

- **Files on GitHub**: a file in a public repository opens from its page (`https://github.com/OWNER/REPO/blob/BRANCH/PATH`) or from its raw link. It is read from `raw.githubusercontent.com`, or from `media.githubusercontent.com` if it is stored with Git LFS.
- **When a log cannot be read**: the server of the log must let other sites read it (CORS), and a page served over HTTPS cannot read `http://` URLs other than `localhost`. A web page cannot work around either. The status bar then says so and offers a link to download the file; open the saved file with File > Open Game Log or by dropping it on the window. An HTTP error such as 404 is shown as it is.

## Not included

Binary logs (v1–v3), the UDP / TCP transports and the S-expression protocols, and Qt-specific features (window style, quit, auto quit).

## Known limitations of this beta

- Opening a log from a URL was tested with headless Chrome and Firefox on Linux, from the single-file HTML on disk: against an HTTP server on the same machine, and against GitHub (a log from its page and its raw link, and a file stored with Git LFS). Not tested yet from the GitHub Pages version (HTTPS).
- The 3D view keeps 60 fps at 1920×1080 in Firefox on a desktop GPU with everything on. Without a GPU (software rendering), it is much slower; turning off the shadows helps the most.
- Tested with headless Chrome and Firefox on Linux, against the replay server and against the asio-based rcssserver on the same machine. Not tested yet: browser shortcuts that the app takes over (Ctrl+1–0, Ctrl+I, Ctrl+L, F11 and others) in desktop browsers, connections from another machine on the LAN, connections from the GitHub Pages version to `localhost`, and Safari.
