The first beta of rcssmonitor-web, a browser-based monitor for the RoboCup Soccer Simulator 2D server (rcssserver). It follows the features and the look of rcssmonitor.

**This is a pre-release** for trying it out and for feedback. The major version follows rcssserver: this beta is for the asio-based rcssserver that will be released as version 20, the first with WebSocket connections. The stable 20.0.0 will come when the repository moves to the rcsoccersim organization; the GitHub Pages address below changes then.

## Downloads

- **rcssmonitor-web-v20.0.0-beta.1.html**: the whole app in one file. Save it and open it from disk (`file://`) to replay logs and to connect to a server anywhere on your LAN.
- **rcssmonitor-web-v20.0.0-beta.1-dist.zip**: the multi-file build, to serve from your own web server.
- The same version runs on GitHub Pages (https://hidehisaakiyama.github.io/rcssmonitor-web/), for logs and servers on `localhost`. A page served over HTTPS cannot open `ws://` connections to other machines.

## Features

- **Live games** over WebSocket with the JSON monitor protocol: start the asio-based rcssserver (development builds report 19.0.0) with `server::ws_port=6080` and connect. Live mode follows the newest frame; step back to look at earlier ones. Automatic reconnection, and a disconnection after 5 seconds without data, as in rcssmonitor.
- **Referee commands**: kick off, drop ball, free kicks, yellow and red cards, and play mode changes (with the coach mode on the server), from the menu bar and the field's pop-up menu.
- **Game logs**: JSON and text (v4–v6), gzip or not; open with the menu, Ctrl+O or drag and drop. Play, stop, step, speed (5–5000 ms per frame), jumps to the goals and to a cycle, loop.
- **2D field** drawn like rcssmonitor: players with their states, stamina, view areas, catch, tackle and kick areas, offside lines, ball prediction, flags, grid, score board with penalty shoot-outs, team logos, measuring tool, zoom and focus.
- **Preference dialog** with rcssmonitor's Show, Canvas, Color and Font tabs; the player type list; the shortcut list. Settings are saved in the browser; URL parameters stand in for rcssmonitor's command line options (`?connect=1&server_host=192.168.0.10&show_view_area=on`).
- rcssmonitor's keyboard shortcuts.

## Fixed compared with rcssmonitor

Live display stopping after 65,535 frames; parsing problems with JSON logs (unknown keys, the view quality, players stored in array order) and with text logs (long team logo strings, stray lines); `foul_push_r`; the offside lines; the left goalie's catch area color; back_pass in Change Playmode sending nothing; "Fix" in the player selection selecting Auto right; the initial Illegal Defense color; sorting the two-number columns of the player type list. See `docs/parity.md`.

## Not included

Binary logs (v1–v3), the UDP / TCP transports and the S-expression protocols, the 3D view (planned), and Qt-specific features (window style, quit, auto quit).

## Known limitations of this beta

- Tested with headless Chrome and Firefox on Linux, against the replay server and against the asio-based rcssserver on the same machine. Not tested yet: browser shortcuts that the app takes over (Ctrl+1–0, Ctrl+L, F11 and others) in desktop browsers, connections from another machine on the LAN, connections from the GitHub Pages version to `localhost`, and Safari.
